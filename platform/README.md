# HUTCA · 计算机协会信息平台

湖南工学院计算机协会信息平台。课程作业 2（题目 A）本地可运行版本。

它不是一个管理后台，而是 **信息发布 + 成员入口**：让新加入的人知道协会是什么、部门怎么选、这周交什么、资料去哪找。

![首页预览](docs/screenshots/home-hero.png)

## 5 分钟跑起来

要求：Node.js 18 或更高版本。项目没有 npm 依赖，不需要 `npm install`。

```bash
cd platform
node server.js
```

打开 <http://localhost:3000>。

## 已实现

- **协会介绍（首页）**：是什么、2019 年成立、2023 年重组、做什么、指导老师、往期活动、大事记。
- **部门页**：4 个部门的目标、负责什么、学习目标、任务清单、招新介绍。
- **成员名单**：严格只显示姓名 + 班级，支持按班级筛选。
- **作业区**：内容、要求、截止时间；登录后按班级隔离，只显示自己的作业；不接收在线提交。
- **学习资料**：按部门 / 类型筛选，链接到官方文档、模板和清单。
- **专业交流 / 社会服务**：两个板块，分别展示活动记录、可参与项目、交流主题和活动照片墙。
- **登录与权限**：服务端 Session、scrypt 密码哈希、HttpOnly Cookie、登录频率限制、作业按班级过滤。
- **站内搜索**：部门、成员、资料、交流内容；登录后才把本人作业纳入搜索。
- **响应式**：桌面、平板、390px 手机宽度均无横向滚动。

## 一页结构图

```text
浏览器
  public/index.html
  public/app.js          ← 单页路由、页面组件、登录态、搜索
  public/styles.css      ← 设计系统与响应式
        │
        │ fetch /api/*
        ▼
Node.js 内置 HTTP 服务（server.js）
  ├─ GET  /api/public    → 协会、部门、成员（仅姓名/班级）、资料、交流
  ├─ GET  /api/me        → 当前登录成员
  ├─ POST /api/login     → scrypt 校验 + 创建 Session Cookie
  ├─ POST /api/logout    → 销毁 Session
  ├─ GET  /api/homework  → 必须登录；按 className 只返回本人班级
  └─ 静态文件 / SPA 回退
        │
        ▼
data/db.json             ← 公开内容（不是页面硬编码）
data/users.json          ← 演示账号的 salt + hash
```

## 数据与权限

数据不在页面里，统一放在 `data/db.json`。服务端只把公开内容发给浏览器：

- `members` 在 API 层被重新映射为 `{ name, className }`，不会把学号、邮箱、手机号发到前端。
- `homeworks` 根本不进入 `/api/public`；只有 `/api/homework` 在登录后返回，并按当前账号的 `className` 过滤。
- `users.json` 只存 scrypt 的 salt 和 hash，不存明文密码。
- Session 存在服务端内存，浏览器只拿到 HttpOnly Cookie；重启服务后需要重新登录。

## 三条我踩的坑

1. **登录报错时整页重渲染，输入被清空。**
   最初在 `catch` 里直接 `render()`，错误提示出现了，但学号和密码没了。后来改成只更新表单里的 `.form-error`、恢复按钮状态并聚焦学号，不再重绘整页。

2. **手机端登录后，用户胶囊把品牌名挤成两行。**
   桌面端显示“头像 + 姓名 + 箭头”没问题，390px 下加上搜索和菜单就放不下。移动端改成只显示头像，姓名放进下拉菜单，品牌名恢复单行。

3. **站内搜索的标题和说明粘在一行。**
   搜索结果原来是两个 `span`，默认 `inline`，所以“技术研发部让每个人从会用工具……”连在一起。改成 `display:block` 后，标题、说明、类型各占一行。

## 修改数据

- 协会信息、大事记、部门、成员、作业、资料、交流内容：改 `data/db.json`。
- 演示账号：运行 `node scripts/hash-password.js` 重新生成 `data/users.json`。
- 页面视觉：改 `public/styles.css` 顶部的 design tokens。
- 新增页面：在 `public/app.js` 的 `renderPage()` 里加路由，并在 `NAV` 中加导航。

## 已知限制

- 这是课程项目，不是生产系统：Session 存在内存，JSON 是只读数据源，没有并发写入和管理员后台。
- 成员、活动、作业等数据为示例数据，可替换为协会真实资料。
- 部署到公网前需要补：HTTPS、Secure Cookie、持久化 Session、CSRF 策略、真实账号发放与审计。
